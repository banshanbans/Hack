# 长者友好家（AnjuGuard）

> 🏆 **抖音 AI 创变者计划 · 视觉搜索赛道 全国一等奖** · 面向适老化居住环境的多模态 AI 安全检查与整改辅助产品

长者友好家聚焦一个具体问题：家庭中的松动地垫、通道杂物、洗浴区缺少支撑、照明不足和高处取物等风险并不总是难以发现，但家庭从“看见问题”到“决定先改什么、怎么改、需要多少预算”仍然缺少低门槛工具。

项目把家庭环境采集、风险定位、用户确认、A/B/C 整改方案、结构化参考预算和报告串成一个可执行流程。它不是让模型自由给分或输出报价，而是让模型负责发现与解释候选，让版本化规则负责等级、评分、覆盖度、方案和价格边界。

## 当前可演示主链路

1. 填写最少的家人情况并选择房间。
2. 上传 1–6 张照片，完成格式、尺寸和质量检查。
3. 对可见风险返回结构化区域、解释和证据。
4. 在评分前合并重复风险，由确定性规则计算参考分和独立覆盖度。
5. 用户确认问题后选择 A/B/C 三档整改方案。
6. 由结构化价格规则汇总预算并生成报告。

## 差异化设计

- **证据优先**：进入正式结果的风险必须有归一化区域、空间对象、快照或用户圈选证据。
- **评分可复现**：相同输入和规则版本得到相同结果，未拍区域不会被当作安全。
- **整改可执行**：A 档强调立即止险，B 档强调性价比，C 档强调长期专业改造。
- **实时与正式分离**：扫描期提示只用于引导，不直接计分；代表画面会重新进入正式分析。
- **安全降级**：无可靠深度时只保留二维证据，不生成虚假世界锚点。

## 多端架构

| 层 | 责任 |
|---|---|
| React H5 | 档案、房间、照片、实时相机、风险、方案、预算和报告 |
| iOS | `WKWebView` 容器、原生拍照、RoomPlan / ARKit / LiDAR 采集增强 |
| FastAPI | Assessment、媒体、任务、Provider、规则、报告和 SQLite 持久化 |
| AnjuCore | 可测试的领域模型、规则、风险状态和坐标解析 |
| AI Provider | 服务端模型调用、Schema 校验和风险候选解释 |

## 真实能力边界

- 照片正式评估、规则评分、独立覆盖度、A/B/C 方案、参考预算和报告是当前稳定主链路。
- H5 实时相机、iOS 深度定位和视觉语音顾问已有代码，但受功能开关控制，仍需真实供应商账号和多设备外部验证。
- 整改后自动复查、城市化价格和抖音内容承接仍属于规划能力。
- 本项目没有接入抖音 API，也不宣称已有站内发布、增长或转化数据。
- 产品只分析画面中可见的居家环境风险，不属于医疗诊断、建筑验收、消防检查或施工报价。
