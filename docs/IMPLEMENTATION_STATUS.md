## 明确未实施

H5 P1/P2 尚未实施：视频抽帧、更细的分房间规则库、跨图片空间融合、整改前后复查对比、PDF 导出和按城市价格。iOS 仍未接入 v2 评分与方案。跨房间永久地图、直播、商品服务和训练管线也未实施。

2. 部署 HTTPS 分析服务并配置服务端密钥；
3. 在支持空间扫描的 iPhone 上执行真机测试记录；
4. 建立 30–50 张获授权的质量样本并记录召回、误报、定位和建议质量；
5. 完成卧室、客厅、卫生间三类现场连续演示。
