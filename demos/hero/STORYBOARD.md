# 《长者友好家》Hero Demo 分镜脚本

## 成片定位

- 时长：28 秒，16:9，优先按 1920×1080 录制。
- 节奏：先建立设备质感，再展示“检查—证据—分析—改造”的产品价值，最后落到品牌。
- 语气：克制、温暖、可信。不使用“自动认证”“绝对安全”等过度承诺。
- 文字：主画面仅保留手机内产品 UI 和结尾品牌，旁白为可选项。

## 字幕版本

如果现场环境吵杂，不使用完整旁白字幕，只在必要时叠加以下四句：

1. 00:09 扫描居住空间
2. 00:15 每一处提示，都有画面依据
3. 00:19 从风险分析，到改造建议
4. 00:24 长者友好家 · 细微改造，步步心安

## 录制执行

1. 用 `?time=2.5`、`7`、`11`、`16`、`20.5`、`25.8` 逐镜检查构图。
2. 录制前确认已加载正式录屏；如果使用内置动态界面，对外明确标注为产品流程演示。
3. 先录一条纯画面，再在后期添加音乐、提示音和可选旁白，避免现场录音影响质感。
4. 保留 00:27–00:28 的完整淡黑，方便单条成片收尾和展台循环。
