## 目录

1. 不可突破的边界

## 1. 不可突破的边界

- 不宣称医疗诊断、跌倒概率预测、建筑验收、无障碍认证、消防检查、工程检查或全屋安全认证。
- 不将未拍摄区域视为安全；单房间或低覆盖度结果必须称“当前已检查区域安全参考分”。
- 不让模型、Agent 或前端改写最终风险等级、评分、规则价格或预算合计。
- 不执行模型生成的 SVG、HTML、脚本或任意工具参数。
- 不将实时相机临时建议写成正式风险。
- 不把 Mock、Demo、静态素材或未经授权的数据当作真实模型效果。
- 不恢复本地视频文件选择、自动抽帧、代表帧选择或视频帧正式识别。

## 2. 证据与规则完整性

每个正式风险至少需要一项可追溯证据：归一化 bbox、归一化 polygon、RoomPlan 对象/表面 ID、快照引用、世界坐标或用户手动圈选。

照片链路必须校验：

- bbox 的 `x`、`y`、`width`、`height` 均在 0–1，宽高大于 0，且不越界；
- polygon 至少三个点，每个点均在 0–1；
- 图片旋转、裁剪或缩放后使用正确逆变换；
- 风险代码来自当前房间和规则版本允许的白名单；
- 相同物理风险跨图、跨帧只扣分一次；
- 规则与价格版本随报告保存。

缺证据、越界或 Schema 不完整时，拒绝进入正式结果，不用文本自行修复。

## 3. 隐私与安全

- 获取照片、相机和麦克风前取得用户主动授权。
- 不上传证件、医疗记录、屏幕中的密钥或与任务无关的个人信息。
- 模型密钥只放服务端，不进入浏览器、Skill manifest、报告或日志。
- 相机临时帧默认不持久化；需要缓存时使用分钟级 TTL 并在退出后清理。
- 日志不记录原图、完整个人档案、访问 token、内部堆栈或模型密钥。
- 分享 token 必须不可猜测且有过期时间。
- `session.private.json` 使用 `0600`，不得加入压缩包或版本库。

## 4. 失败降级

| 错误 | 行为 |
|---|---|
| `no_usable_media` | 给出一个具体补拍动作，不生成高确定性结论 |
| `profile_incomplete` | 引导补齐三项档案后再正式分析 |
| Provider 超时、429、容量忙 | 保留输入并等待/重试，不启用 Demo |
| Provider 拒绝或结构无效 | 更换视角或图片，不升级不完整候选 |
| 覆盖不足 | 返回已检查区域结果与缺失视角，不直接扣安全分 |
| RTC、语音或视觉工具失败 | 保存单张代表画面，退回照片正式评估 |
| 无可靠深度 | 使用二维证据卡，不创建世界锚点 |
| 未知价格 | 保留在 `unknown_items`，不补造金额 |
| 复查能力未实现 | 输出人工对照步骤，不生成 resolved 结论 |

## 5. 模型与产品评测

只有使用获授权、按房型与风险分层的数据集后，才可报告真实效果。

### 视觉模型指标

- 风险候选召回率：标注风险中被正确发现的比例；
- 误报率：正式候选中不成立的比例；
- 定位质量：bbox IoU、polygon IoU 或关键区域命中率；
- 证据完整率：正式输出中具有合法区域的比例；
- Schema 通过率：模型输出一次通过结构校验的比例；
- 跨视角去重准确率：同一问题被正确合并且不同问题未误合并的比例；
- 分房型、分风险、分光照、分设备的差异。

### 实时视觉语音指标

- 首个结构化临时建议时延；
- 语音打断成功率和转写意图准确率；
- 质量/变化门控后每分钟真实模型调用数；
- HTTP 降级率、排队超时率、前后台资源释放成功率；
- 临时建议转为用户保存代表帧的比例；
- 临时建议与正式风险的一致性，只作评测，不自动等同。

### 安全与可用性门禁

- Safari、Chrome、App 内 WKWebView 的权限拒绝与恢复；
- LiDAR 与非 LiDAR 设备的二维降级；
- 旋转 JPEG、bbox、深度图和世界坐标一致性；
- VoiceOver、Dynamic Type、44pt 触控区和非纯颜色表达；
- 弱网、超时、取消、上传中断、模型拒绝和空结果。

## 6. 增长和 ROI 指标

以下指标用于规划与实验，不是当前成绩：

| 指标 | 定义 |
|---|---|
| 入口点击率 | 进入检查入口人数 / 内容或搜索落地页曝光人数 |
| 有效媒体率 | 至少一张照片通过质量检查的任务 / 开始上传的任务 |
| 首次检查完成率 | 获得正式房间结果的任务 / 创建评估的任务 |
| 风险确认率 | 用户确认成立的正式风险 / 展示给用户的正式风险 |
| 方案选择率 | 至少选择一项 A/B/C 的报告 / 完成检查的报告 |
| 报告分享率 | 产生有效分享的报告 / 完成检查的报告 |
| 复查率 | 在规定周期内发起整改后复查的报告 / 有已选方案的报告 |
| 风险到行动转化率 | 进入已处理或复查状态的风险 / 用户确认成立的风险 |
| 单次有效检查成本 | 模型、媒体、计算与服务成本 / 完成的有效检查数 |

冷启动先建立基线，不预填虚构提升值。每次实验只改变一个入口、拍摄引导或结果表达，并同时观察完成率、误报反馈、退出率和单位成本，避免只优化流量而牺牲安全质量。
